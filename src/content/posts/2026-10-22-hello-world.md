你好，我是**技术派罗恩**。

94 年，全栈工程师，坐标苏州。专科起步、专升本、最后从苏州大学计算机毕业——这条路走得不算快，但 10 多年互联网研发干下来，每一步都算数。

## 这个站聊什么

三件事：

1. **AI 实战**——我当前的主业是 AI Agent 开发，Node / Python 双栈。这里会有真实项目的一手复盘：什么方案跑通了、什么坑踩过了，而不是二手新闻的转述。
2. **全栈工程**——从 React 前端、NestJS 后端到 Electron 桌面端、Docker 部署的完整链路。
3. **工程师搞钱**——技术人怎么把技能变成产品、把产品变成收入。工程师的时间很贵，别只用来打工。

## 这个站本身就是一篇技术文章

与其写一篇《如何搭建个人网站》，我直接把过程做成了这个站，几个关键决策：

- **框架选 Astro**：纯静态 HTML 输出、默认零 JS、Lighthouse 接近满分。对内容站来说，这比任何 SPA 框架都合适——搜索引擎和 AI 爬虫拿到原始 HTML 就能读全文。
- **部署零新增成本**：站点跑在一台 1GB 内存的甲骨文小机上，复用已有的 Cloudflare Tunnel 和 Apache，只加了一个 vhost，内存零增长。国内国外访问都走 Cloudflare 边缘。
- **发布走 GitHub Actions**：`git push` 之后自动构建、自动 rsync 到服务器。写文章的姿势就是提交一个 Markdown 文件。

这套链路的细节（包括为 AI 引擎做的 GEO 优化），我会在下一篇文章里完整拆解。
