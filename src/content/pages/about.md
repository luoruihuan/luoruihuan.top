## 现在在做什么

当前的主攻方向：

1. **AI Agent 开发**——用 Node 和 Python 构建真正跑在生产里的智能体应用，而不是 demo
2. **FDE（Forward Deployed Engineer）**——前沿部署工程师的实战方法论：贴近客户的工程、快速交付、闭环反馈
3. **GEO（Generative Engine Optimization，生成式引擎优化）**——研究品牌与内容如何被 ChatGPT、Perplexity、豆包等 AI 引擎推荐和引用，并做出了自己的 GEO 运营工作台 [GeoLens](https://geo.luoruihuan.top)
